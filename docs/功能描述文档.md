## 一、App Store 描述文案（可直接粘贴）

拾帧 FrameScoop 是一款纯原生 macOS 图片浏览器，按文件夹整理你的图片，界面与交互贴近系统「照片」App，启动即用、无广告、无内购。

**主要功能**

- 文件夹浏览：侧边栏添加任意图片文件夹（自动包含子目录），重启后自动恢复访问权限；也可直接浏览系统照片图库（含 iCloud 照片）
- 舒适浏览：自适应网格、多种排序方式、缩略图尺寸可调；双击进入沉浸式全屏查看，双指缩放、拖拽平移、方向键翻页，底部胶片条快速定位
- 智能筛选
  - 连拍识别：按画面相似度自动分组连拍照片，一眼看清重复画面
  - 人脸模糊检测：自动标记人脸模糊的照片（红/黄角标），挑图不再靠肉眼
  - 闭眼检测：识别闭眼照片（红/黄角标），与人脸筛选共享同一次分析
  - 分析结果跨会话持久化，同一文件夹第二次打开无需重算
- 高效选择：拖拽框选、按住 Shift 点击范围选择（Finder 风格）、批量移到废纸篓 / 导出 / 复制
- 元数据面板：像素尺寸、色彩空间、拍摄设备、EXIF（光圈 / ISO / 焦距 / 快门）
- 文件监控：文件夹内容变化自动刷新，无需手动重载
- 导入进度可视化：分析进度清晰展示，完成后自动隐藏

**隐私优先**

- 完全离线运行，不发起任何网络请求，不收集任何数据
- App Sandbox 沙盒隔离，最小权限原则（仅访问你选择的文件夹与照片库）
- 所有分析（连拍 / 模糊 / 闭眼）均在本机完成，照片永不离开你的设备

支持 macOS 14 及以上，Apple Silicon 与 Intel 通用。

## 二、详细功能说明（产品文档）

### 1. 文件夹浏览

- 侧边栏管理多个图片文件夹，树形逐级展开子目录，每行显示递归图片数
- 文件夹访问授权通过 macOS 安全作用域书签持久化，重启后无需重新授权
- 任意层级的子文件夹都可选中浏览（书签常驻激活）
- 内置「照片图库」节点，经 Photos.framework 读取系统照片库（含 iCloud 同步照片）

### 2. 网格浏览

- 自适应列数，随窗口宽度变化；图片按真实宽高比布局
- 排序：创建时间 / 修改时间 / 文件名等，升降序可切换
- 缩略图尺寸多档可调
- 双击打开沉浸查看；右键菜单（打开 / 在 Finder 中显示 / 移到废纸篓）

### 3. 选择与批量操作

- 单击切换选中；拖拽框选（≥3pt 触发矩形框选，Shift 拖拽加选）
- **Shift 点击范围选择**（Finder 风格）：点击 A 后按住 Shift 点击 B，自动选中两者之间的所有照片；连续 Shift 点击从同一锚点扩展；连拍布局下按视觉顺序
- 批量：移到废纸篓（原生可恢复）、导出、复制
- 「只显示选中」过滤视图

### 4. 智能筛选（右侧边栏）

| 筛选 | 原理 | 表现 |
| --- | --- | --- |
| 连拍筛选 | dHash 感知哈希相似度分组 | 连拍组内编号显示，可批量保留/删除 |
| 人脸模糊筛选 | Vision 人脸检测 + 拉普拉斯方差 | 全模糊标红、部分模糊标黄（face.dashed 角标） |
| 闭眼检测 | Vision 人脸 landmarks + 眼睛纵横比（EAR） | 闭眼标红/黄（eye.slash 角标） |

- 三者的分析在图片导入时一次预计算完成（512px 缩略图单次取图），结果按 mtime 失效跨会话持久化
- 阈值可调：连拍相似度（0-30）、模糊阈值、闭眼阈值；调整后即时复用已算数据，不重取图

### 5. 沉浸查看

- 毛玻璃 + 暗色背景全屏
- 双指缩放、拖拽平移、方向键上下张、`i` 键切换信息面板、`Esc` 退出
- 底部胶片条：LazyHStack 懒加载，单击跳转、空格标记选中
- 双击方向键触发 2 秒间隔幻灯片自动播放

### 6. 元数据

- 像素尺寸、色彩空间、拍摄设备、EXIF（光圈 / ISO / 焦距 / 快门等）
- 经 `mdls`（带超时保护）与 ImageIO 双通道获取

### 7. 文件监控与导入进度

- DispatchSource 文件监控：文件夹增删改自动刷新，无轮询开销
- 「图片数据导入」进度条：仅在分析过程中显示，完成后短暂显示对勾并自动淡出隐藏

### 8. 性能设计

- 缩略图：CGImageSource 降采样 + 磁盘缓存（上限 2000 张）+ 大图解码串行化（内存预算 ≤200MB）
- 预计算：流式批处理（16 张一批回主线程）、每 128 张存盘点、协同取消（切文件夹即停旧任务）
- 网格 cell Equatable 跳过未变化重渲染

### 9. 隐私与安全

- 零网络：不申请网络权限，无任何联网行为
- 沙盒最小权限：仅 3 项（sandbox / user-selected 文件读写 / 书签持久化）
- 无第三方 SDK、无数据采集；全部计算在本机
